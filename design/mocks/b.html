Open source · MIT · a DailyBot alternative you own

Standup, async. On your own Slack app.

sunup DMs each person a short form at their local morning hour, then posts one tidy digest to your channel. Blockers stay on the board until they're resolved, with their age, so nothing quietly rots.

Deploy your own GitHub

You run it. There's no hosted service and no "Add to Slack" button.

About fifteen minutes, start to finish.

Cloudflare Workers free tier, or plain Node. Your Slack app, your database, your data.

1

Deploy the Worker

Clone, install, create the database, ship it.

npm install
npx wrangler d1 create sunup
npm run db:migrate
npm run deploy
2

Create the Slack app from the manifest

Paste the bundled manifest, then add two secrets.

npx wrangler secret put SLACK_BOT_TOKEN
npx wrangler secret put SLACK_SIGNING_SECRET
3

Run /sunup setup

Invite the bot, pick questions and a time, join.

/invite @Sunup
/sunup setup
/sunup join
Reads no messages. Only the scopes it needs:
chat:writecommandsim:writeusers:read

sunup only sees what people type into its own forms. users:read is for timezones.

sunup

Async daily check-ins for Slack, deployed to your own Cloudflare account. Open source, MIT. A DailyBot alternative you own: no hosted service, no per-seat bill.

# about 15 minutes, free tier
$ git clone https://github.com/briancorbin/sunup
$ cd sunup && npm install
$ npx wrangler login
$ npx wrangler d1 create sunup
$ npm run db:migrate
$ npm run deploy
✓ live on your *.workers.dev

Then: create the Slack app from the bundled manifest, wrangler secret put SLACK_BOT_TOKEN and SLACK_SIGNING_SECRET, /invite @Sunup, /sunup setup. Prefer plain Node? That works too.

What you get

check-ins
At your chosen hour, in each person's own timezone, sunup DMs a short form. Questions are configurable. One reminder goes out before the digest.
digest
One tidy message in the channel summarizing everyone's answers. Late check-ins update it in place.
blockers
Tracked until resolved. The next prompt asks "still blocked?", the digest shows age ("blocked 3 days"), App Home has a live board.
kudos
/kudos @teammate for shipping the thing, with a 30-day leaderboard.
/sundown
The evening checkout twin of the morning check-in. Plus a weekly retro and an optional 1-5 mood pulse (team average only, 3+ responses).
report / export
/sunup report gives a charted, signed, 24-hour report page. /sunup export gives CSV. Vacation mode: /sunup snooze 5.

What it can't see

  • chat:writepost the digest and DMs
  • commandsrespond to /sunup, /kudos, /sundown
  • im:writeopen the check-in DM
  • users:readtimezones, so 9am means 9am

It only ever sees what people type into its own forms.
